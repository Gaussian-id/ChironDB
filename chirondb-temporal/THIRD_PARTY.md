# Temporal component provenance

This internal crate contains Rust adaptations of the sources below. Its source-level oracles are rebuilt from independently pinned upstream files. The exact SHA-256 of each consumed donor file and Java verification jar is in [sources.json](verification/sources.json). Third-party code retains its attribution and licenses.

| Donor | Adapted behavior and origin | License / changes |
|---|---|---|
| [InfluxDB OSS 2.9.0 tsm1](https://github.com/influxdata/influxdb/tree/fde85a2af2a62eec0bb84216786c7a48a61cbd5e/tsdb/engine/tsm1) | `timestamp.go` encoder RLE/raw/scaled packed deltas; `float.go` Gorilla window and end sentinel; `bool.go` MSB-first values; `encoding.go` packBlock/unpackBlock; `writer.go` header, Write/WriteIndex and index entries; `reader.go` key/entry framing. The oracle additionally compiles `bit_reader.go`. | [InfluxData MIT](licenses/InfluxDB-MIT). The Rust reader bounds block counts and verifies CRCs. The private file header/footer differ from TSM. The Go oracle uses the original reader's readKey/readEntries and scalar decoders and the original writer, with a typed harness adapter. Its writer.go includes a routine attributed to the Go standard library; see [Go BSD notice](licenses/Go-BSD). |
| [jwilder/encoding](https://github.com/jwilder/encoding/blob/b4e1701a28ef/simple8b/encoding.go) | Simple8b selectors, including upstream's special one runs and streaming window. Rust packs and expands words with safe scalar operations. | [MIT, Jason Wilder](licenses/simple8b-MIT). Go module version and checksums are in oracle.mod and oracle.sum. |
| [go-tsz](https://github.com/dgryski/go-tsz) / [go-bitstream](https://github.com/dgryski/go-bitstream/tree/3522498ce2c8) | InfluxDB float.go credits go-tsz as its origin. The InfluxDB pin is the source of the port; its comment does not identify an ancestral go-tsz revision. |

**Dependency boundaries.** The Rust library uses the existing workspace versions of crc32fast and its cfg-if dependency (both MIT OR Apache-2.0). Inspect with `cargo tree --locked -p chirondb-temporal`. The Go oracle's only module dependencies are go-bitstream and jwilder/encoding. The Java verifier compiles the two original classes against TsFile/common, IoTDB server/calc-commons, Guava (Apache-2.0) and slf4j-api (MIT). These jars are pinned by digest in the harness and are downloaded into the verification work directory. TSBS runs as a separate generator with upstream's go.mod/go.sum. None of the Go or Java packages is a runtime dependency of this crate.

The InfluxDB 3.12.1 [line-protocol parser](https://github.com/influxdata/influxdb/tree/692ea4a9943fc343c5fdf830d7dff82eef1f7fca/core/influxdb_line_protocol) remains a candidate for a future ingest interface.
