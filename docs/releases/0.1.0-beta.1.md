# ChironDB 0.1.0-beta.1

ChironDB's first public beta adds a native, single-node property-graph overlay
to vector collections. Existing points are graph vertices, so exact bounded
traversal and graph-constrained dense or hybrid retrieval share the same WAL,
snapshot, compaction, encryption, and recovery lifecycle as vector data.

## Supported beta surface

- Graph lifecycle, typed edges, edge properties, deletion, and deferred endpoint imports.
- Exact bounded traversal over outgoing, incoming, or bidirectional edges.
- Graph-constrained dense and hybrid search.
- HTTP, gRPC, ChironWire/ChironQL, and typed Rust and Python SDK access.
- Durable restart, snapshot/restore, compaction, encryption, and tenant/RBAC enforcement.

## Deliberate exclusions

- Graph-aware multi-search.
- Distributed graph placement or cross-node traversal.
- Shortest-path, random-walk, or graph-algorithm APIs.
- Graph statements over the PostgreSQL-compatible wire surface; they continue
  to reject with SQLSTATE `0A000` and a compatibility hint.

## Validation status

Comprehensive graph acceptance and the full release/security validation matrix
remain incomplete. Encrypted-query performance, large-scale recovery, external
TLS rotation, and reproducible builds still require release evidence.

Use this beta for evaluation. Exercise recovery procedures and validate recall,
latency, and throughput on representative workloads before production use.
